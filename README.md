# 🎄 圣诞节页面 - Christmas Page

一个漂亮的圣诞节主题网页，包含动画效果、交互功能和节日氛围。

## ✨ 功能特色

- 🎄 **精美圣诞树**: 带有闪烁彩灯和装饰品的动画圣诞树
- ❄️ **飘落雪花**: 真实的雪花飘落动画效果
- 🎁 **互动礼物**: 点击礼物盒获得惊喜消息
- 🎵 **背景音乐**: 圣诞节主题音效和背景音乐
- 💡 **彩灯控制**: 可以开关圣诞树上的彩灯
- ✨ **鼠标特效**: 鼠标移动时的星星跟随效果
- 📱 **响应式设计**: 适配各种设备屏幕

## 🎮 交互功能

### 按钮控制
- **🎵 播放音乐**: 播放/暂停背景音乐
- **❄️ 雪花开关**: 开启/关闭雪花效果
- **💡 彩灯开关**: 控制圣诞树彩灯

### 键盘快捷键
- `M` - 音乐开关
- `S` - 雪花开关  
- `L` - 彩灯开关
- `空格` - 随机打开礼物

### 鼠标交互
- 点击礼物盒获得惊喜
- 鼠标移动产生星星特效
- 悬停效果和动画

## 🚀 如何运行

1. 克隆或下载项目文件
2. 在项目目录中启动HTTP服务器：
   ```bash
   python3 -m http.server 8000
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 📁 文件结构

```
├── index.html      # 主页面HTML结构
├── style.css       # CSS样式和动画
├── script.js       # JavaScript交互功能
└── README.md       # 项目说明文档
```

## 🎨 技术特点

- **纯前端实现**: 使用HTML、CSS、JavaScript
- **CSS动画**: 丰富的CSS3动画效果
- **Web Audio API**: 音效和音乐播放
- **响应式布局**: 适配移动端和桌面端
- **现代浏览器兼容**: 支持主流现代浏览器
